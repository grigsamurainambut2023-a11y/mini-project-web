# Mini Project Web Portofolio

Proyek ini adalah website portofolio sederhana yang dibangun untuk memenuhi Tugas Individu 1 Pemrograman Web.

## Teknologi yang Digunakan
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (Vanilla)

## Fitur
- Desain responsif
- Navigasi yang mulus
- Interaksi tombol dengan JavaScript

## Cara Menjalankan
1. Clone repositori ini.
2. Buka file `index.html` di browser.
